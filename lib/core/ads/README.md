# ads

AdMob service wrapper for banner and rewarded ads (Milestone 5).

`reward_gate.dart` is the hook features already call: the 4x4-6x6 solvers,
advanced Academy lessons and daily-challenge hints. Milestone 4 ships
`OpenRewardGate` (everything unlocked); Milestone 5 swaps in the rewarded
video flow through `rewardGateProvider`.
